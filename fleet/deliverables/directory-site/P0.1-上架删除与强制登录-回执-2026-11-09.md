## 1. 重新上架

编辑弹层继续 `lock-meta`，保存仍走 `toToolEditPayload`，不带 status。状态下拉在编辑时改成纯文字，并写明这里改不了状态，也不会因此重新上架。

已下架行改为文字按钮「重新上架」。点击 `PUT /api/admin/directory/tools { id, status: 'published' }`（没有 name）→ `setAdminToolStatus` → `setOverride(slug, 'hidden', false)`。前台列表、详情、sitemap 读的都是这面旗，揭隐后恢复。

三个自测 slug 没有单独拦截。审核通过 / 确认收款仍然不清 `hidden`（P0 那条测试还在）。

## 2. 删除策略

仍在架上（未 hidden，且控制台状态是 published）不能直接删。提示仍是「仅未发布的工具可删除，请先强制下架」，只在这条规则真的没满足时出现。没有一键清空全部预设。

**社区提交**（PeachChat、callfreechat 这类）：已下架后工具台显示删除。删除时 `DELETE FROM submissions WHERE slug = ?`，并拆掉合集关联。不是只打 hidden。工具列表来自已公开的 submissions，行没了就不会再出现；`/api/tools` 也不再返回它。非目录预设会清掉 hidden，避免这个 slug 以后被重新提交时一直 410。已存在的匿名待审没有删、没有回填。

**catalog.json 预设**（ChatGPT / Claude / Cursor / Midjourney 这类）：不删 `dir_tool` 行。写入 `dir_tool.status = 'deleted'`，并在 `tool_overrides.removed = 1`（同时 hidden = 1）。合并列表跳过 deleted，不再从 catalog.json 活回来。`removed` 会并进公开的 hidden 集合，所以列表、详情 410、sitemap、榜单都继续不展示。重新上架若撞上 `removed` 会拒绝，避免把墓碑揭掉。已有库在首次读写覆盖时用现有的 `ensureOverrideColumns` 补 `removed` 列；本次没有对生产库执行。

## 3. 提交未登录

前端 `/submit`：`DirectorySubmitForm` 先看现有会话。没有会话就去 `/sign-in?next=<当前提交页>`，表单不渲染，不能填完再匿名提交。登录仍是现有 Google OAuth，没有接设置页里的占位开关。

后端 `POST /api/submit`：没有有效 `sub` 时在 `createSubmission` 之前返回 401，`code` / `reason` 为 `submit_signin_required`，中文「提交产品需要先用 Google 登录。」英文 “Sign in with Google before submitting a product.” 已有匿名待审不动。

## 4. 榜单

`boardRows` 和 `/weekly` 自己拼的 ranking 都改走 `rankedBoard`：先丢掉 `tool_overrides.hidden` 里的 slug（墓碑也在这个集合里），再把剩下的从 1 重新编号，限额在过滤之后截取。首页「本周榜单」在接口 `week: null` 时仍用 catalog 里 10/26–11/1 那一周；Claude 若已下架，Consensus 成为第 1 名，后面的往前补，不会空着第 1 名，也不会留下能点进 410 的卡片。

同一路径：首页榜、`/weekly` 当前周和历史周、详情页右侧热门、`TopPicks`（首页和最新收录的侧栏）。
