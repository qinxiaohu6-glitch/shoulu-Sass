## 四个必须记住的事实

1. **现行实现在 `nuxt/`，根目录的 `*.html` 和同名目录是旧站的静态产物。** 改根目录那些文件不会影响 `dirtool.com`。旧 Python 代码在 `legacy/`，只读。
2. **内部链接必须走 `localePath()`。** `@nuxtjs/i18n` 在 `prefix_except_default` 下不会自动加 `/zh` 前缀，写 `to="/tools"` 会把中文读者送到英文站——而且不报错。
3. **`useRuntimeConfig(event)` 必须带 event。** 在 Workers 上不带它拿到的是构建期配置，`NUXT_*` 永远不合并进来，症状是「配置齐全但 `/admin` 永远 404，日志里什么都没有」。
4. **页面上写的功能不等于真的能用。** 这个项目出现过「定价页写全站右栏实际只有 2 页」「后台有开关但开关不写服务端」「导航链到一个后端不存在的页面」。验证方式只有一个：改数据 → 看页面 → 查网络请求。
