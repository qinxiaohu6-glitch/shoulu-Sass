## 一、竞品本质：同一套框架，对方做了"减法 + 聚焦"

ProductsBoost 是 Next.js + Cloudflare 的周榜型目录站。技术和我们不同（我们 Nuxt 4），
但**信息架构和叙事逻辑几乎同源**：左侧栏 + 中栏周榜 + 右栏广告，一周一榜，免费上榜，
付费买"更快/更显眼/反链"。差别在于对方把它做到了极致聚焦，我们则堆了大量空壳页。

### 关键数据（实测）

| 维度 | ProductsBoost | 我们（线上） |
|---|---|---|
| sitemap URL 数 | **98** | 数百（含 100+ maker 页、社区、博客、合集、标签） |
| 页面类型 | 周榜首页 / Hall of fame / alternatives(8) / categories(14) / product(63) / 5 个法务+提交+定价+广告 | 上述全部 + 社区 + 创客(52) + 博客 + 合集 + 标签 + 统计 + SEO 诊断 + 创客故事 |
| 首页主体 | 周榜产品行（20 个） | Hero + Billboard 十宫格 + 三栏介绍 |
| 商业化 | Free $0 / Boost $4.99 一次性 / Featured $29 周 / Sidebar $9 周 | Free / Standard / Featured / Pro + Billboard 竞价 + 广告 |
| 促销表达 | 确定价 + 50% off 倒计时 + 左下常驻 Boost 卡 | 黑五条 + 浮标 + 划线价 |
| 空壳页 | **几乎没有** | 社区（空）、创客（自动派生的 52 页）、博客（模板）、合集、标签 |

### 竞品真正的优点（值得抄）

1. **信息架构极简**：98 个 URL，没有社区/创客/博客/合集/标签/统计。每个 URL 都有明确用途。
2. **周榜驱动首页**：首页 = 本周榜（产品行按票数排），不是营销落地页。周选择器在顶部。
3. **确定价、无模糊表述**：`$4.99` / `$29 per week` / `$9 per week`，从不写"约"。
4. **付费位与周榜数据隔离**：Boost 是金色高亮行 + 徽章 + dofollow，明确标注，不混进票数。
5. **广告位可视化 + 明码标价**：右栏 4 个 Sidebar 卡 $9/周 + 中栏 Featured $29/周，每页可见。
6. **上周 Top3 常驻小组件**（右下角）：把"往期赢家"变成社会证明。
7. **24h traffic + 本周数字条**：1,154 page views / 20 products / 84 upvotes，全部现算。
8. **徽章机制**：Gold verified、Winner badge、Featured on ProductsBoost（可嵌入自己站换 dofollow）。
9. **alternatives 对比页**（8 个）：程序化 SEO，每个都是"我们 vs X"表格 + FAQ。
10. **每个核心页都有可见 FAQ**，与 FAQPage JSON-LD 同源。

### 明确不抄

- 竞品的品牌文案、产品数据、DR/流量数字（我方实测 `dirtool.com` DR4=0，禁止引用虚数）。
- 竞品的 Creem 支付（我们用已打通的 Waffo）。
- 50% off 这类虚假持久折扣（我方已决定"实付价即展示价"）。
- 社区 / 创客 / 产品买卖市场（本轮按要求整体移除；产品买卖计划无落地记录且有法律/防刷风险）。

## 二、改造范围（本轮落地）

### A. 移除社区与创客（最高优先，用户明确要求）

**目标**：Google 抓取 `/community`、`/community/makers`、`/community/makers/*`、`/makers/*` 时
返回 **真正的 404**（不是软 404、不是 200 空页），并从 sitemap / llms.txt / ai.txt / 导航 / 页脚 / 内链
彻底清除，让搜索引擎自然除名。

**做法**：
- 删除页面文件：`app/pages/community/**`、`app/pages/makers/**`。
- 删除 `server/middleware/03-maker-urls.ts`（旧地址 301 到创客页的重定向）。
- 导航：`app/layouts/default.vue` 去掉 sidebar/topbar/footer 三处社区/创客入口。
- `server/routes/sitemap.xml.ts`：去掉 community/makers 两类路径与生成循环。
- `server/routes/llms.txt.ts` / `ai.txt.ts`：去掉社区/创客描述与 Cite 条目。
- 内链：`app/pages/faq.vue`、`pricing.vue`、`products/[slug].vue`、`settings/index.vue`、
  `admin/submissions.vue`、`shared/content/blog-template.ts`、`shared/content/settings-i18n.ts` 里
  指向 community/makers 的链接改为去掉或指向产品库。
- 产品页的 maker 字段**保留为纯文本**，不链接创客页（详情页作者栏不再是死链）。
- 新增 `server/middleware/04-retired-routes.ts`：对已下线路径显式返回 404（走 Nuxt `createError`），
  保证不是 SPA 软 404。

**验证**：线上探针换成 local dev（本轮不部署）；`/community*`、`/makers*` 全 404；
sitemap/llms/ai.txt 0 残留；全仓 grep 无外链残留（法务页历史说明除外）。

### B. 删掉空壳/华而不实页面

按竞品"98 URL 原则"，本轮**下线或隐藏**（同样返回 404 并从所有出口清除）：
- `/blog` + `/blog/[slug]`（只有模板 outline，无真实内容）
- `/collections` + `/collections/[slug]`（空）
- `/tags` + `/tags/[slug]`（空壳，标签在详情页已有 chip）
- `/stats`（数字页，与首页数字条重复，竞品没有）
- `/feed`（竞品有 RSS，我们这个先保留评估）

**保留**（有真实功能/数据）：`/products`、`/categories`、`/weekly`、`/leaderboard`(新增)、
`/pricing`、`/submit`、`/advertise`、`/billboard`、`/book-ad`、`/guest-post`、`/seo-check`、
法务页、后台、用户设置、登录注册。

### C. 首页按竞品三栏重构

- 左栏导航：Products / Categories / Weekly / Leaderboard / Pricing / Advertise / Submit。
- 中栏顶部：周选择器（Week 47 · Live · 剩余天数）+ 数字条（24h page views / products / upvotes）。
- 中栏主体：本周产品行（rank + logo + 名称 + 徽章 + tagline + 域名 + 票数按钮），
  付费位金色高亮 + `Featuring` 标，与票数数据隔离。
- 右栏：4 个 Sidebar 广告卡（$9/周 + 明码 + Book）+ 上周 Top3 + 常驻 Boost 促销卡。
- 保留我们已有的 Billboard 十宫格为独立 `/billboard`，首页只留一个精简入口。

### D. 商业化与文案对齐

- 所有价格改确定价，删"约/about"与无数据源数字。
- Boost/Featured 位一律显式标签（`FEATURED`/`BOOSTED`）+ `sponsored nofollow`。
- FAQ 与 JSON-LD 同源，价格运行时注入。
- 新增 `/leaderboard`（名人堂）：往期每周 Top3，黑色卡片金色高亮（抄竞品视觉，不抄数据）。

## 五、实际落地记录（2026-11-17）

### 最终决策（与上面方案的差异，以此为准）

- **社区 / 创客**：物理删除 5 个页面文件 + `03-maker-urls.ts` 重定向中间件；
  新增 `00-retired-routes.ts`（编号 00，优先于旧 URL 重定向）对这些路径及 `.html`/`/zh` 变体
  返回**真正的 HTTP 404**（非软 404、非 301）。产品详情页 maker 字段改为纯文本。
- **blog / tags / collections**：同样物理下线并 404（竞品无此类页型，且我方为空壳）。
- **stats / feed**：**保留**（有真实数据支撑），仅从 sitemap 移除 stats、从导航做弱化处理；
  不物理删除，避免误伤。这是对方案 B 段的收窄——方案里原本写"下线 stats"，实际没删。
- **首页增强**（对齐竞品周榜驱动的视觉）：
  - 新增 `app/components/WeeklyPulse.vue`：周标签 + 剩余天数 + 4 格活数字 + 上周 Top3，
    数据全部来自 `/api/board` 与目录实时统计，零硬编码。
  - 首页中栏目录区顶部插入 WeeklyPulse；产品行补域名 + 分类的 meta 行。
- **名人堂**：新增 `app/pages/leaderboard.vue`（竞品 Hall of fame），
  黑色卡 + 金/银/铜高亮的每周 Top3，数据来自 `/api/board` 归档；
  已接入侧栏 / 顶栏 / 页脚 / sitemap / llms.txt。
