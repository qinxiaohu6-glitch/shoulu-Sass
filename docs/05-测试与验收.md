## A. 已验证项

### A.1 设置页接真实订单（2026-11-04）

**怎么造的测试数据**：本地 `nuxt dev` + 手工签发的会话 cookie（`NUXT_SESSION_SECRET=test-session-secret`）+ 4 条混合记录。

| # | 记录 | plan | status | awaiting_payment | paid_at |

**结果**：

| 检查 | 期望 | 实际 |
|---|---|---|
| 概览摘要（英文） | 待付款不算进审核中 | `1 in review · 2 live · 1 awaiting payment` ✅ |
| 付款记录卡片 | 只列已付款的 | `Beta Widgets · $19 · 2026-11-04 · INV-TEST-1` ✅ |
| 付款合计 | $19 | `$19` ✅ |
| 列表页 4 行状态 | 四种状态各自正确 | `Awaiting payment` / `Pending review` / `Live + Paid 2026-11-04` / `Live` ✅ |
| 中文版 | 同样的数字与文案 | `审核中 1 · 已上线 2 · 待付款 1`，`付款记录` / `合计` 都在 ✅ |
| 无提交的新用户 | 不渲染付款卡片 | 卡片整块不出现，空态正确 ✅ |
| 后台 `/admin` | 无回归 | 队列与统计正常 ✅ |

**这条验证针对的 bug**：把「付费档但未付款」显示成「审核中」，会让用户等一个不可能到来的决定（`reviewSubmission` 明确拒绝审批这种记录）。

### B.5 SEO

| # | 检查 | 命令 | 期望 |

| 1 | sitemap 有内容 | `curl -s https://dirtool.com/sitemap.xml \| grep -o "<url>" \| wc -l` | 192（含已上线提交会更多） |
| 2 | sitemap 不含 `.html` | `curl -s …/sitemap.xml \| grep -o "\.html" \| wc -l` | 0 |
| 3 | hreflang 三件套 | `curl -s …/sitemap.xml \| grep -o 'hreflang="[^"]*"' \| sort -u` | `en` / `zh-Hans` / `x-default` |
| 4 | robots | `curl -s https://dirtool.com/robots.txt` | 有 `Sitemap:` 行 |

**第 1 条注意**：sitemap 是一整行 XML，`grep -c "<url>"` 数的是**行**不是**条**，永远返回 1。必须用 `grep -o … \| wc -l`。

**第 7 条**：

```bash
curl -s https://dirtool.com/zh | grep -o 'href="/[^"]*"' \
  | grep -v 'href="/zh' \
  | grep -vE 'href="/(_nuxt|assets|favicon\.|apple-touch)' \
  | grep -v 'href="/"' \
  | sort -u
```

`href="/"` 是语言切换按钮（它该指向英文首页），静态资源不带语言——两者都要排除。

## D. 回归测试最小集

改完任何东西，至少跑完这 10 条。**全部可以复制粘贴。**

```bash
BASE=https://dirtool.com

# 1. 英文主路由
for p in / /tools /categories /tags /makers /weekly /just-added /pricing \
         /submit /sign-in /privacy-policy /terms-of-service \
         /tools/claude /categories/coding /tags/api /makers/anthropic; do
  printf "%-28s " "$p"; curl -s -o /dev/null -w "%{http_code}\n" "$BASE$p"
done

# 2. 中文主路由（前缀不能丢）
for p in /zh /zh/tools /zh/categories /zh/weekly /zh/pricing /zh/submit \
         /zh/tools/claude /zh/categories/coding; do
  printf "%-28s " "$p"; curl -s -o /dev/null -w "%{http_code}\n" "$BASE$p"
done

# 3. 设置页（未登录会 302 到登录页，302 也算正常）
for p in /settings /settings/submissions /settings/profile /settings/tickets; do
  printf "%-28s " "$p"; curl -s -o /dev/null -w "%{http_code}\n" "$BASE$p"
done

# 4. 后台无 cookie 必须 404
curl -s -o /dev/null -w "admin: %{http_code}\n" "$BASE/admin"

# 5. 公开 API
for p in /api/tools /api/overrides /api/ads /api/board /api/votes; do
  printf "%-18s " "$p"; curl -s "$BASE$p" | head -c 80; echo
done

# 6. 旧 URL 单跳
curl -s -o /dev/null -w "%{http_code} → %{redirect_url}\n" "$BASE/pricing.html"
curl -s -o /dev/null -w "%{http_code} → %{redirect_url}\n" "$BASE/dashboard.html"

# 7. 主域统一
curl -sI https://www.dirtool.com | head -1
curl -sI http://dirtool.com | head -1

# 8. 中文页链接前缀（期望空输出）
curl -s "$BASE/zh" | grep -o 'href="/[^"]*"' \
  | grep -v 'href="/zh' \
  | grep -vE 'href="/(_nuxt|assets|favicon\.|apple-touch)' \
  | grep -v 'href="/"' \
  | sort -u

# 9. sitemap 条数与是否含 .html
echo -n "urls: "; curl -s "$BASE/sitemap.xml" | grep -o "<url>" | wc -l
echo -n "html: "; curl -s "$BASE/sitemap.xml" | grep -o "\.html" | wc -l

# 10. 未审核条目的详情页必须 404
curl -s -o /dev/null -w "%{http_code}\n" "$BASE/tools/this-slug-does-not-exist"
```

**判据**：1/2/3 全 200（设置页允许 302）；4 是 404；5 全部 `{"ok":true…}`；6 是 301 且目标正确；7 是 301；8 空；9 的 `html` 为 0；10 是 404。

> 本地跑这套清单时把 `BASE` 换成 `http://127.0.0.1:3000`（或 `nuxt dev` 实际占用的端口）。
> 本地 `grep` 第 8 条会多出 `/_nuxt/...` 这类开发态资源路径——上面的命令已经把它们排除了；如果还有输出，那是真的漏了前缀。

## E. 数据清理

测试产生的记录要删掉，否则它们会出现在线上列表里。

```bash
cd nuxt

# 看有哪些
npx wrangler d1 execute product-atlas --remote \
  --command "SELECT slug, name, status, plan, created_at FROM submissions ORDER BY created_at DESC LIMIT 20"

# 删一条
npx wrangler d1 execute product-atlas --remote \
  --command "DELETE FROM submissions WHERE slug='deploycheck'"

# 删测试投票
npx wrangler d1 execute product-atlas --remote \
  --command "DELETE FROM votes WHERE slug='deploycheck'"

# 删测试广告
npx wrangler d1 execute product-atlas --remote \
  --command "DELETE FROM ads WHERE name='Test Client'"
```

⚠️ **`DELETE` 不可撤销。** 删之前先 `SELECT` 确认一遍，或用 §B.6 的导出做一份备份。
